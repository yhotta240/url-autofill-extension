## URL AutoFill

URLを開くだけで，指定した内容をWebフォームへ自動入力できるChrome拡張機能です．

## 主な機能

- URLを開くだけで，指定した内容をフォームへ自動入力
- 入力先と値を指定して，自動入力用のURLを作成・コピー
- よく使うURLを名前付きで保存し，一覧から開いて再利用

## 制限

- パスワード，ファイル，hidden入力，非対応の入力型，無効・読み取り専用の欄は変更しない
- 入力先を特定できない場合は入力しない
- iframe，Shadow DOM は対象外
- 保存したURLは端末内に保持し，入力値やURLはログに出力しない
