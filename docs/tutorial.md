## 自動入力URLを生成する

入力欄と値を指定してURLを作成し，そのURLを開くとフォームへ自動入力できます．

1. 入力したいページを開き，ツールバーからURL AutoFillのポップアップを開きます．
2. 設定タブの「対象ページURL」を確認します．現在のURLが入りますが，変更や手入力もできます．
3. 「要素の指定方法」を選び，入力欄と「入力値」を指定します．複数指定する場合は「項目を追加」，不要な項目はゴミ箱ボタンで削除します．
4. 生成URLを確認し，「URLをコピー」を押します．エラーがあれば入力内容を修正してください．
5. 「URL AutoFill を有効にする」をオンにし，コピーしたURLを開きます．初期状態はオフです．

編集中の内容は保存されないため，ポップアップを閉じる前にURLをコピーしてください．

## 入力欄を指定する

入力欄の `name` / `id` 属性かCSSセレクタを使います．画面上のラベルとは異なるため，不明な場合はChromeの開発者ツールで入力欄を検証して確認してください．

### name / id

「name / id」を選び，「フィールド名」に属性の値を入力します．例えば `name="email"` または `id="email"` なら，`email` と指定します．

`name` が優先され，見つからなければ `id` を使います．複数の入力欄に一致する場合はCSSセレクタで絞ってください．

### CSSセレクタ

「CSSセレクタ」を選び，入力欄を1つに絞る指定を入力します．

| 入力欄の例                                     | CSSセレクタ                          |
| ---------------------------------------------- | ------------------------------------ |
| `id="email"`                                   | `#email`                             |
| `name="email"` の入力欄                        | `input[name="email"]`                |
| `name="plan"`，`value="plan-b"` のラジオボタン | `input[name="plan"][value="plan-b"]` |

対象が見つからない場合や，複数に一致する場合は入力されません．

## 入力値を指定する

| 入力欄の種類                 | 入力値                                                      |
| ---------------------------- | ----------------------------------------------------------- |
| 文字・メールアドレス・検索欄 | 入力したい文字列                                            |
| 数値欄                       | 数値（例：`123`）                                           |
| 日付欄                       | `YYYY-MM-DD` 形式（例：`2026-10-24`）                       |
| 複数行の入力欄               | 改行を含む文字列                                            |
| 選択リスト                   | 選択肢の `value` 属性の値（表示名とは異なる場合があります） |
| チェックボックス             | `true` / `1` でチェック，`false` / `0` / 空欄で解除         |
| ラジオボタン                 | 対象の `value` 属性と同じ値で選択，空欄で解除               |

入力値を空欄にすると，対象の入力欄を空にします．選択リストは1つだけ選択します．

## 制限と注意点

- URLに入力値が含まれるため，パスワードなどの機密情報は指定しないでください．
- URLは16,384文字，入力項目は100件までです．
- パスワード・認証コード・カード情報・ファイル選択の欄や，編集できない欄は対象外です．
- Chromeの設定画面やChrome Web Store，埋め込みページなどでは利用できません．サイトによっては入力が反映されない場合もあります．
- フォームは自動送信しません．入力結果を確認してから送信してください．
